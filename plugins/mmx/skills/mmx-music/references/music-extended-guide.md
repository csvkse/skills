## 古风调性与乐器选择经验

### 调性建议（实测）

| 情绪 | 推荐调性 | 实测效果 |
|------|---------|---------|
| 仙侠悲情、离别、壮烈 | `D minor` | 空灵苍凉，适合《落星引》风格 |
| 温暖治愈、安然、平静 | `G major` | 明亮温柔，适合《此间小满》风格 |
| 淡淡忧郁、思乡 | `A minor` | 内敛细腻 |
| 宏大叙事、史诗 | `E minor` | 厚重有力 |

### BPM 建议

| 风格 | BPM | 说明 |
|------|-----|------|
| 极慢空灵（仙侠引子）| 58~65 | 留白多，意境深 |
| 舒缓治愈 | 70~78 | 自然流动，不压迫 |
| 叙事主歌 | 80~90 | 轻快讲述 |
| 流行副歌 | 100~120 | 情绪推进 |

### 古风乐器搭配方案

| 风格 | 乐器组合 |
|------|---------|
| 仙侠悲情 | 洞箫（主）、二胡（情感）、古筝（和声）、琵琶（点拨）、编钟（开篇/结尾） |
| 温暖治愈 | 古筝（主）、琵琶（轻快）、洞箫（柔和）、二胡（情感补充）、轻弦乐（托底） |
| 江湖豪侠 | 琵琶（主）、箫（苍凉）、鼓（节奏）、弦乐（推进） |
| 空灵出尘 | 箜篌、编钟、洞箫、古琴（极简，留白多） |

### cover 模式用于版本对比的技巧

当需要同一首歌多个演绎版本时：
1. 先用 `generate` 生成一个基础版
2. 将该基础版作为 `--audio-file` 传给 `cover`，修改 `--prompt` 调整风格
3. 这样新版本在结构上与原版相似，但在演绎细节上有变化
4. 适合：改变人声风格、调整情绪浓度、换一种乐器质感

## 限额处理：generate 失败时的备选方案

当 `mmx music generate` 遇到以下错误时，主动询问用户是否切换到 `music-cover` 翻唱模式：

**触发条件**（任意一条）：
- 错误含 `rate limit` / `429` / `quota exceeded` / `RPM`
- 连续两次生成返回空文件或异常退出
- 用户提到"限额了"、"生成失败"、"配额不足"

**询问话术**：

> `music-2.6` 当前遇到了限额/错误。
> 可以切换到 **翻唱模式（music-cover）** 绕过限额——
> 需要提供一段参考音频（可以是任意同风格的 mp3/wav），
> 模型会基于参考音频的风格重新演绎当前歌词。
>
> 是否使用翻唱模式继续？如果有合适的参考音频请告诉我路径或 URL。

**cover 备选命令模板**：

```bash
# 用翻唱模式生成（需要参考音频）
mmx music cover \
  --prompt "中国古风仙侠，清冷仙气女声，洞箫二胡古筝" \
  --audio-file 参考音频.mp3 \
  --lyrics-file 歌词.txt \
  --format wav \
  --sample-rate 44100 \
  --out 歌曲名_cover.wav \
  --quiet
```

**cover 模式注意**：
- 参考音频决定整体风格和时长基准（6秒～6分钟，最大 50MB）
- 歌词通过 `--lyrics-file` 或 `--lyrics` 传入
- cover 模型：`music-cover`（付费）/ `music-cover-free`（默认）
- cover CN 区不支持 URL 输出，使用 `--out` 写盘
